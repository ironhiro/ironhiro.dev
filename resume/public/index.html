About

CUDA/C++ 홀로그램 생성 알고리즘 연구로 시작해, 4D 영상 솔루션의 Windows 클라이언트를 거쳐 인생네컷 키오스크 솔루션의 신규 아키텍처 설계와 결제·하드웨어 통합을 맡았습니다. 카메라 입력부터 합성, 인쇄까지 전 구간을 직접 다뤘습니다.

미디어 쪽에서는 OpenCV·LUT 색 보정과 Canon SDK · FFmpeg · Windows Graphics 파이프라인을, 장비 쪽에서는 RS232 / MDB 제어와 국내외 결제 디바이스 7종을 하나의 인터페이스로 묶는 구조를 설계하고 구현했습니다.

운영 중인 서비스를 멈추지 않고 .NET Framework → .NET Core, WinForms → WPF, MVVM Helper 종속 → DI 기반 구조로 단계적으로 옮겼습니다. 동작하는 코드보다 다음 작업자가 모듈만 교체하면 되는 구조를 남기는 데 우선순위를 둡니다. 비전, 디바이스 제어, 결제처럼 도메인 지식이 쌓일수록 더 잘할 수 있는 분야에서 계속 일하고 싶습니다.
