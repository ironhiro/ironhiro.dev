인생네컷 키오스크 솔루션 리뉴얼 및 유지보수 2024 – 2026.04

6년 이상 운영된 .NET Framework + WinForms 레거시는 이벤트·결제 추가 시 분기 코드가 누적되어 신규 기능마다 사이드이펙트 점검 비용이 커지는 상태. 이를 .NET 6.0 + WPF + MVVM 기반 신규 솔루션으로 전환하면서, 단순 포팅이 아닌 확장 가능한 구조 설계를 목표로 잡았습니다.

  • MVVM Helper 종속 → DI 기반 OOP 아키텍처로 전환. 결제·카메라·이벤트 로직이 ViewModel에 직접 결합되어 유사 프로그램마다 프로젝트를 새로 만들어야 하던 구조를, Microsoft.Extensions.DependencyInjection 도입으로 서비스 레이어를 분리하고 핵심 도메인을 인터페이스 단위로 추상화. 결제기·이벤트 추가 시 기존 코드 수정 없이 구현체만 DI 컨테이너에 등록하는 방식으로 정리.
  • 공통 모듈을 Git Submodule + 내부 패키지로 분리. Face Tracking, Background Removal, Canon EDSDK 래퍼, OpenCV/LUT 후처리 등 중복 구현되던 모듈을 분리하고 솔루션 간 동일 인터페이스로 통일.
  • 이벤트 플러그인 구조 설계. 연 10건 이상 단기간에 들어오는 콜라보·시즌 이벤트를 유형(스탬프형 / 필터형 / 릴레이형 / 영상연동형)별 인터페이스와 IoC 등록 규약으로 추상화해, 신규 이벤트는 리소스 + 콘텐츠 로직만 작성하면 등록되는 플러그인 방식으로 전환. 룰렛 스탬프·히든 메시지·농심 60주년·쿠팡 트래블·절단네컷 등을 동일 구조 위에서 처리.
  • Custom Control 체계. 외부 UI 프레임워크의 라이선스·런타임 부담 없이 키오스크 전용 인터랙션(터치 응답, 풀스크린 전이, 카메라 라이브뷰 합성, 인쇄 미리보기)에 대응하도록 ControlTemplate + Attached Behavior 기반 재사용 컴포넌트 체계 구축.
